# Aset 2D raster

PNG/WebP transparan yang tidak bisa dibuat dengan kode (foto, gambar tangan). Ilustrasi vektor dibuat sebagai komponen di `src/components/`, bukan di sini.

| Folder | Isi |
|---|---|
| `common/` | Dipakai banyak episode |
| `<id>/` (misalnya `sp02/`) | Khusus satu episode |

Spesifikasi (format, ukuran, nama file) dan cara memakai: `docs/guides/04-ASET-2D.md`. Kalau suatu saat memakai aset dari luar, lisensinya harus komersial dan dicatat di `LICENSES.md` di folder ini.
