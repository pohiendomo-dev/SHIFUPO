# Logo resmi (opsional)

Taruh logo resmi Shifu Po di sini kalau berbeda dari stempel 風 bawaan video.

| File | Isi |
|---|---|
| `logo.svg` | Paling disarankan: tajam di semua ukuran |
| `logo.png` | Alternatif: PNG transparan, lebar minimal 1200 px |

Logo belum otomatis dipakai: setelah file ada, `LogoPlate` di `src/components/Brand.tsx` perlu disambungkan (path sebagai konstanta di `src/lib/brand.ts`). Panduan: `docs/guides/06-PENEMPATAN-ASET.md`.
