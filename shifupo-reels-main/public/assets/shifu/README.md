# Foto Shifu Po

Taruh file di folder ini, lalu render ulang (`npm run produce -- sp01`). Tidak perlu ubah kode.

| File | Wajib | Isi |
|---|---|---|
| `shifu.png` | Ya | Foto Shifu Po, latar dihapus (PNG transparan), setengah badan sampai seluruh badan, menghadap sedikit ke kiri. Tinggi minimal 1600 px. |
| `shifu-fan.png` | Opsional | Lengan dan kipas dipotong terpisah (PNG transparan, ukuran kanvas sama dengan `shifu.png`), supaya kipas bisa bergoyang. |

Tips: foto dari banner website (kemeja merah-hitam, kipas bulu) sudah cocok dengan gaya video. Potong rapi di sekitar rambut, karena latar kertas terang membuat sisa latar terlihat jelas.
